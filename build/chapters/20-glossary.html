Appendix A

Glossary

Definitions run alphabetically letter by letter, ignoring spaces, case and punctuation; digits sort first. Numbers locate chapters defining or relying on terms, in book order; passing mentions are omitted.

A

Abliteration
Editing model weights without further training to remove a refusal pattern found by comparing internal responses to harmful and harmless prompts.07
ACID atomicity, consistency, isolation, durability
Database transaction guarantees. Atomicity: all changes happen or none do. Consistency: declared constraints hold after commit. Isolation: the chosen level controls which concurrency anomalies are prevented. Durability: committed data survives a crash. Postgres with pgvector lets a memory row and its vector commit together.0811
Agentic search
Agent-directed retrieval using grep, glob and file reads, checking results and searching again. It needs no index and sees current files, but costs tool calls and depends on the agent's judgment.0005
AGENTS.md
A repository-root Markdown file coding agents load for project instructions, an open convention described as "a README for agents".0102
ANN approximate nearest neighbor
Search returning near vectors without checking every vector, using indexes such as HNSW or IVFFlat. Results can differ from exact search, trading recall for speed.081119
AOF append-only file
Redis's rewritable on-disk recovery record represents current data rather than every original command. Fsync forces writes to storage: always (every write), everysec (about once a second) or no (the operating system decides).09
Apache AGE
A Postgres extension that runs openCypher graph queries.0814
API application programming interface
The interface for calling another program, such as a hosted model or memory service.0013
Archival memory
In Letta, memory outside the context window, read through a search tool. Blocks stay in context.0001
Asterisk
An open-source PBX that Chapters 22 and 23 propose as the phone switch between carrier and local speech software. Neither runs it.2223
AudioSocket
An Asterisk protocol that streams raw audio (PCM, pulse-code modulation) over a socket to a local program, here a proposed Pipecat worker (see Pipecat).2223
Audit trail
An append-only record for later review: who read or changed which record, when and under which rule.08172223

B

BAA business associate agreement
A written agreement with an outside party that handles protected health information for a US health provider. Chapter 22 says to check each vendor's data flow to see if one is needed.22
Bead
A Beads work item: title, status, owner and links to blocking items.01
Beads bd
A coding-agent task tracker storing work items as a dependency graph, showing blocked and ready items and their owners.0112
BEAM
A memory benchmark of 100 conversations up to 10 million tokens, with 2,000 validated questions. Its authors report that models with 1 million tokens of context degrade as dialogues grow.16
BFCL Berkeley Function-Calling Leaderboard
A tool-calling benchmark. Chapter 06 cites BFCL-V4 scores for small models.06
bfloat16, float16 and float32
Weight and vector formats: float32 takes 4 bytes per number, float16 and bfloat16 take 2. bfloat16 keeps float32's exponent range with fewer precision bits; float16 has a narrower range. Chapter 03 checks which formats EmbeddingGemma 2 supports; FP8 is an 8-bit float taking 1 byte.000304
BGE-M3
An embedding model that produces dense, sparse and multi-vector output, with an 8192-token input.0305
Binary quantization
Keeping one bit per vector number, so the packed values alone are 32 times smaller than 32-bit numbers, before scales or metadata. Recall loss varies with model and data, so stores usually rescore with retained full vectors.0311
Bitemporal
Keeping valid time and recorded time for each fact. Also called "two timelines" (Chapter 14) and "both clocks" (Chapters 22 and 23). See Valid time and Recorded time.142223
BM25
A keyword scoring formula. It rewards rare query words with diminishing returns for repeats and adjusts for note length.000512
Both clocks
See Bitemporal.

C

Cache
A fast, disposable copy of recomputable data, keyed until expiry or eviction. Never keep the only copy there; recompute misses or doubtful entries from the source.0010
Cache key
A cache-entry label including every result-changing input: model version, parameters, prompt version and user scope. Example: emb:sha256(canonical_JSON([tenant, model_revision, parameters, prompt_version, text])) hashes a canonical JSON array, avoiding ambiguous field joins.10
Candidate pool
The top N results of the first searches. Later steps only reorder or trim it, so pool recall caps subsequent stages.05061319
Cartridges
A research method that trains a small KV cache for a corpus once instead of prompting with it. Its authors report using 1/38.6 as much memory as in-context learning at matched quality; a small test in Chapter 16 kept the memory saving but lost accuracy.0016
CC-BY-NC Creative Commons Attribution-NonCommercial
A license, used by models such as Jina v5, that allows noncommercial use only; commercial use needs separate permission.0305
Checkpoint
Four meanings. 1. Agent framework (Chapters 00, 13, 15, 17): a saved snapshot of a run's state, for resuming. 2. Model (Chapters 06, 07, 16): a saved set of weights. 3. Event log (Chapter 17): a worker's saved position. 4. SQLite (Chapter 12): copying the write-ahead log into the main file. See also Checkpoint fork.0006071213151617
Checkpointer
Saves agent state after each step, keyed by thread id, for conversation resumption.1517
Checkpoint fork
Starting branches from one saved checkpoint. Each branch keeps its own draft memory; trusted application code promotes only approved facts to the shared Store. Replaying a checkpoint rewinds neither the Store nor an external action. See Chapter 13, Forked planning.1317
Chunk chunking
A note, document or conversation segment embedded and stored as one unit. Where you cut decides what can be found.0305
CLAUDE.md
A hand-written instruction file that Claude Code loads at the start of every conversation, as a user message after the system prompt: the simplest always-loaded memory.0001
CMB Coding Memory Benchmark
A coding-memory benchmark with separate diagnostic question-answering and execution-graded code-editing tracks. Retrieval recall, QA score and task resolution measure different things; never subtract one from another.16
CoALA
A paper that splits a language agent's memory into four kinds: working, episodic, semantic and procedural.00
Code-linked freshness
Storing the file, symbol and commit that each fact about code was true at, and re-checking or suppressing the fact when that code changes.01
Cognee
A memory framework that uses a model to extract facts into a knowledge graph, with a vector index beside it.1314
ColBERT
A retrieval model family built on late interaction (one vector per token). ColBERTv2 compresses to cut the extra storage.0405
Cold start
The first call after a service starts, while the model and database load.0619
Collection
A named vector-store record group. Isolation and filtering depend on the store; test that one credential cannot read another collection.11
ColPali and the ColQwen family
Multi-vector models that keep one vector per visual patch of a page image. Their authors introduced ViDoRe to argue that embedding page images beats OCR. See Multi-vector.04
Community summary
A model-written summary of a closely linked entity cluster.14
Compaction
Shrinking a long conversation by summarizing or dropping older turns so it fits the context window.16
Compiled page
A Markdown page the agent wrote from sources, such as a summary, entity, concept or comparison.02
Consolidation
After-turn work: merging duplicates, summarizing old episodes into facts and settling contradictions.001316
Constrained decoding
Decoding that permits only tokens consistent with a grammar or supported schema. Check that generation finished before parsing; a valid shape does not make the facts correct.0607
Consumer group
Distributes new Redis stream entries among workers and tracks acknowledgment. A crash after acting but before acknowledging lets another worker claim and repeat the action; make processing idempotent.09
Context database
A system that keeps files unchanged and adds a model-written summary to each directory, so an agent can browse a tree and read summaries at two sizes before opening a file. OpenViking is the example.000218
Context engineering
Anthropic's name for curating the tokens a model sees at inference time. Chapter 16 places the memory tool, editing and compaction under it.1516
Context rot
The drop in a model's reliability as input grows. Chroma reported it across 18 models, even on a trivial repeat-the-text task.0016
Contextual Retrieval
At write time an LLM writes 50 to 100 tokens placing a chunk in its document. That text is prepended to the chunk before the chunk is embedded and, separately, indexed for BM25.05
Context window
A model's maximum usable token span. Earlier messages outside it are directly visible only if the application resupplies them.000615
Continuous batching
Adds and removes requests at every decoding step, letting one GPU serve many calls. Chapters 22 and 23 propose it for vLLM serving; neither runs it.2223
Cosine similarity
The normalized dot product of non-zero vectors: -1 means opposite directions, 0 orthogonal, 1 identical directions. Similar texts usually score high, not necessarily 1.0309
CRM customer relationship management
The system that holds customer records and contact history.212223
Cross-encoder
A model scoring the relevance of a query and note read together. Most rerankers are cross-encoders.05
Crypto-shredding
Making data unreadable by destroying its encryption key. It works only if every relevant copy is encrypted under that key.17
CVE common vulnerabilities and exposures
A public identifier for a known security flaw. Chapter 17 cites two in LangGraph's SQLite checkpointer, Chapter 08 one in pgvector's IVFFlat index build.0817
Cypher
Neo4j's query language for matching node and edge patterns. openCypher is its open specification, used by Apache AGE and FalkorDB.0814

D

Data residency
A rule or design that keeps a region's personal data, models and keys on servers in that region. Chapter 23 designs five isolated data regions.23
Dead-letter queue
A durable place that keeps events whose retries ran out, with event id, attempt count and error, so operators can repair the cause and submit again.17
Dense vector
One fixed-length vector of floating-point or quantized numbers per item. It matches overall meaning and is usually much smaller than a multi-vector one.0305
Dimension
A vector's length in numbers. Models tested in Chapter 03 output 384 to 4,096 numbers per text; other models differ.030811
Directed persistence fixture
A test in which the harness directs the model's tool edits to prove save, recall, resume and delete work. It does not test autonomous extraction quality or the minimum model or GPU.1318
DiskANN
A graph index like HNSW designed for SSD, so it can exceed RAM but is slower per hop.0811
Distillation
Training a small model to imitate a larger one. Chapters 06 and 07 note community uploads called distills; read their base model and procedure from the model card.0607
Document id
A stored-note key. Chapter 19's save replaces that id's note; other APIs distinguish insert, update and upsert.19
DolphinBench
A benchmark (September 2026) of knowledge-work tasks over three personas, each with about 500K tokens of user messages. Submissions report completion, total cost and latency.1617
Dolt
A SQL database with git-style commits, branches and remotes. Beads stores its items in it.01
Dream
In Anthropic's Managed Agents, a research-preview job that reads a memory store and past transcripts, then writes a reorganized memory store.16

E

EHR electronic health record
A practice's clinical record system. Chapter 22 keeps one underneath as the system of record, which the memory layer never replaces.22
Embedding
A learned numerical representation of an input, such as text, an image or audio. Retrieval models are trained to place matching inputs near each other.000304
Embedding inversion
Turning a vector back into its text. Chapter 17 cites exact recovery of 92% of 32-token inputs for GTR-base and 60.9% for a hosted encoder (paper figures, not run here), so a vector index is not anonymized.17
Embedding model embedder
A model turning text or other input into embeddings. It answers nothing and remembers nothing; the store holds the memory.030406
Embedding space
An embedding model's learned coordinate system. Do not mix vectors from different models, revisions or preprocessing in one index unless the vendor documents a shared space.030408
Encoder
A neural network mapping input tokens to representations. Bidirectional text encoders use context on both sides; retrieval models may combine token vectors or keep several. Decoder (left-to-right) embedders can instead use the final token's vector.03
Entity linking
Mapping a text mention to an entity record. Chapter 13 covers Mem0 v3 entity signals. See Entity resolution for duplicate detection.0613
Entity resolution
Deciding whether entity records represent the same thing; a mistake can merge two people into one graph node. See Entity linking for attaching mentions.17
Episode
Raw input, such as a conversation turn, retained as the source for extracted entities and facts.081314
Episodic memory
What happened, in order, with times, usually held in an append-only log such as JSONL or an event table.0012
E-signature levels
Laws such as EU eIDAS distinguish advanced from qualified electronic signatures; a qualified one has the effect of a handwritten signature. Chapter 23 leaves the level for each document to counsel.23
Event log
A durable, append-only record of accepted changes and deletions, from which searchable memory is derived and rebuilt.12171821
EverOS
A self-run, Apache-2.0 memory system that keeps readable Markdown as the canonical source, with SQLite and LanceDB indexes, user and agent tracks and offline reflection. Surveyed in Chapter 13, not run.1318
Eviction
A cache removing items before they expire to free memory, as Redis policies such as allkeys-lru do.0910
Exact search
Search guaranteed to return the nearest neighbors under the chosen distance. By default, pgvector scans eligible rows; latency grows with table size.0811
Extraction
Turning raw conversation into short, separate facts or entities.061314

F

FalkorDB
A property graph database that uses openCypher and speaks the Redis protocol.14
Fencing token
See Lease.
Fine-tuning
Further training that changes a model's behavior. A compliant fine-tune is an alternative to weight editing (abliteration) for reducing refusals.0007
FLAT
A Redis vector index type that scans every stored vector, so results are exact. HNSW is the approximate alternative used in Chapter 09.09
Forgetting
Expiring, deleting or superseding records. Without it a store only grows and stale facts surface. See Soft forgetting.00
FP8
See bfloat16, float16 and float32.
Frontmatter
A short block of settings between two --- lines at the top of a Markdown file.01
FTS full-text search
Keyword search over the words in stored text. SQLite's FTS5 and Postgres tsvector with a GIN index are examples.000812
FTS5
SQLite's built-in full-text search module, which indexes words and ranks matches.000512

G

GBNF
A grammar format llama.cpp accepts to force valid output such as JSON.06
GDPR General Data Protection Regulation
The European Union's data protection law. Chapter 23 takes its storage-limitation and erasure rules as engineering inputs for the EU region, not legal advice.23
Generative Agents
A 2023 study that scored each memory by recency, importance and relevance and used periodic reflection to turn observations into higher-level ones.000515
GGUF
A llama.cpp and Ollama model-file format holding weights and metadata. Vision models add a projector file (see Vision projector).020607
GIN generalized inverted index
A Postgres inverted index for composite values, including tsvector words and JSONB keys and values.08
GitHub Copilot Memory
Facts a coding agent writes and GitHub stores. Repository-level facts cite code and are checked when used; user preferences follow one person across repositories.0113
Golden set
A small file of real questions with their answering note ids. Cover real query types: exact lookups, paraphrases and questions with no valid hit.0517
Graphiti
The open-source engine behind Zep. It keeps a temporal graph of episodes, entities and facts with validity windows, invalidating a replaced fact instead of deleting it.001314
GraphRAG
Microsoft's method that extracts entities and relations, groups them into communities and summarizes each, with global, local and DRIFT search (local search expanded through community summaries).14
Graph search
Walking from named entities along the edges between them. It suits multi-hop and time-aware questions.0014
grep, glob
grep searches inside files for text. A glob is a file-name pattern such as src/**/*.ts.0105

H

HaluMem
A benchmark that counts hallucinations at each memory operation: extraction, updating and question answering. It looks for fabricated, wrong, conflicting and missing memories, so it measures memory quality, not task success or security.1617
Harness
Runs the model and returns saved text to its context window.0001
Heretic
Finds weight edits balancing refusal reduction against base-model divergence.07
Hindsight
A memory framework with three calls (see Retain, recall, reflect). It extracts facts and entities with a model and uses Postgres with pgvector as its primary storage.060813
HIPAA Health Insurance Portability and Accountability Act
The US federal health-privacy law. Chapter 22 treats a permission under it as separate from a telephone-marketing one (TCPA).1622
HippoRAG
Retrieval extracting a corpus entity graph at write time and ranking nodes per query with Personalized PageRank.14
HNSW hierarchical navigable small world
A layered near-neighbor graph, mostly in RAM, searched by node-to-node hops. Fast and accurate but memory-hungry. Chapters 08 and 11 give its settings and compare other indexes.00080911
Honcho
A memory product organized around peers, meaning what one participant knows about another; self-run under AGPL-3.0 or managed.13
Hook
A command a coding tool runs on a lifecycle event, such as a session start or tool call. Memory tools use hooks to capture activity without the model choosing, so audit what they capture.011317
Hot tier
A fast layer, such as Redis, refilled from a durable system-of-record store.09
Hybrid search
Running keyword search and vector search together and merging the two result lists.000508
HyDE hypothetical document embeddings
A method that asks an LLM to write a plausible answer, embeds that answer and searches with it. The invented answer only has to be worded like the real one.05
Hy-Memory
Tencent's Apache-2.0 memory framework with Chat, Working and Coding pipelines. The name also covers a purpose-trained writer model, Hy-Memory-30B-A3B (about 30 billion parameters, 3 billion used per token). Not run.0616

I

Idempotency key
A write identifier recognizing retries as the same request. See Receipt.172223
Idempotent
An operation whose repeated events have the same effect as one.0617
Ingest, query, lint
The three loops of an LLM wiki: add a source, ask a question, check wiki health.02
InjecMEM
Plants a poisoned memory record in one chat turn without store access. Topical cues surface it later; an optimized command inside steers answers.1617
Inject
The final read-path step: place surviving results in context, labeled as data, not instructions.00
Iterative scan
A pgvector setting, available since version 0.8.0, that keeps walking the index until enough rows pass the filter or the scan limits are hit.0811
IVF inverted file
An index scanning only the nearest vector clusters. Low probe counts can beat flat search at scale but miss neighbors in unscanned clusters; high recall can cost more than flat.0811
IVFFlat
pgvector's cluster index. It builds faster and is smaller than HNSW, but the table needs data before you build it. Use pgvector 0.8.7 or later: Chapter 08's pin fixes a CVE in IVFFlat index builds.0819

J

JSONB
A Postgres column type for JSON. It holds per-row attributes, so adding an attribute needs no table change.08
JSONL JSON lines
One JSON object per line in a text file, so appending means writing a new line.0012

K

KL divergence Kullback–Leibler divergence
A number measuring divergence between distributions, here edited versus base next-token probabilities. Heretic uses it to check that an edit barely shifts answers to harmless prompts. It is not a memory-accuracy score.07
KNN k nearest neighbors
The k closest stored vectors: exact with FLAT or sqlite-vec, approximate with an ANN index.0912
Knowledge graph
Memory stored as nodes and edges (see Node, edge); questions are answered by walking the links.14
Known-at recall
Recall of facts whose valid time contains the requested effective date and whose recorded time contains the requested as-known-on date, so a later correction does not rewrite earlier knowledge. Today's retention and access rules still apply.2223
Kuzu
An embedded graph database. Its repository is archived and Graphiti marks its Kuzu driver deprecated, so start nothing new on it.14
KV cache key-value cache
The attention state a model computes for a prompt. Reusing it skips re-reading the prefix. A provider (prompt cache) or local server (see KV-cache offload) can keep it.1016
KV-cache offload
A self-run layer, such as LMCache, that moves a server's KV cache from GPU memory to CPU RAM, disk or remote backends and shares it across requests and engines. It differs from provider prompt caching.10

L

L0, L1, L2
Three levels of one context-database directory. L0 is a one-line abstract and L1 a longer overview, both model-written summaries. L2 is the original or parsed full content, loaded on demand.02
LanceDB
An embedded vector store that keeps versioned Lance tables on disk or object storage.11
LangGraph
An agent framework. Its checkpointers save run state, and its Store keeps JSON documents under a namespace and key.081317
LangMem
Memory extraction tools used with the LangGraph Store. Extraction calls the model you pass in.13
Late chunking
Embedding the whole document with a long-context model, then pooling token vectors per chunk so each carries the surrounding text.05
Late interaction
Keeping one vector per token and comparing query tokens with note tokens. It matches finer detail than one vector per note, at about an order of magnitude more storage (Chapter 05).030511
Lease lock key
A TTL-bound Redis job-holder key. SET lease:<id> <holder_value> NX PX 30000 claims it for 30 seconds using a random holder value. Renew or release only on a matching value, atomically with Lua or equivalent compare-and-set. A stalled worker can outlive its lease. Each grant needs a fencing token: a rising counter. The destination rejects writes below the highest counter seen.09
Legal hold
A reviewed exception retaining records past scheduled deletion. Chapters 22 and 23 assign a human owner and review date; a model never sets or lifts a hold.2223
Letta
A memory framework (also Chapter 00) that keeps labeled memory blocks always in context and a searchable archival memory outside it. The agent edits its own memory with tool calls.010613
LISTEN/NOTIFY
A Postgres feature in which one session sends a NOTIFY on a channel and every session that ran LISTEN on it wakes up.08
llama.cpp
A program that runs GGUF models locally. Its server accepts GBNF grammars and can save a prompt's KV cache to disk.030610
LLM large language model
A language model reading and writing text; here, notes, extracted facts or answers.000205
LLM wiki
A git repository of Markdown pages that an agent writes and updates from source documents. The agent compiles knowledge once and keeps it current instead of rebuilding it per question.0218
LoCoMo
A benchmark of ten very long conversations with question answering, event summarization and dialogue tasks. An independent audit reports incorrect reference answers.0205061314161718
LongMemEval
A benchmark of 500 questions on scalable chat histories, testing extraction, multi-session and temporal reasoning, knowledge updates and abstention.01050613141617
LoRA low-rank adaptation
A small set of trained matrices added to a frozen model, so behavior or knowledge can change without retraining the whole model. Chapter 16 uses it as the baseline for a memory-table paper.16
Lost in the middle
A 2023 study finding that accuracy drops when the relevant fact sits mid-context, even for models built for long inputs.0015
LRU least recently used
A rule for choosing what to evict: the item unused longest goes first. Memcached evicts at the LRU tail.0910

M

Managed cloud memory service
A vendor service that extracts, stores and searches memories, while your application authenticates users and sets scope. Chapter 13 compares Google, AWS and Microsoft Foundry; Chapter 18 says when to pick one. None was run.001318
MaxSim
For each query vector, take its best similarity to any vector of the stored item (page or chunk), then sum those scores as the item's ranking score.0411
MCP Model Context Protocol
The standard for connecting tools to a model. Chapter 13 tests its reference memory server, which keeps a whole-file graph and serializes writes from several processes with a lock.000213
Mem0
A memory framework whose background model extracts short facts into a vector store with one add-only call. Mem0 v3
The Mem0 algorithm as shipped in the pinned mem0ai==2.2.1 Python package. The book uses v3 for the algorithm and mem0ai==2.2.1 for the package.0613
MEM1
A research prototype trained with reinforcement learning to reason and consolidate memory together: each turn it merges new observations into one compact state and discards the rest. Code is released.16
MemAgent
A research prototype trained with reinforcement learning to read a long document in segments and overwrite a fixed working memory. It holds state within one task, not user facts across sessions. Code is released.16
Memanto

Memcached

MemGen

MemGPT

Memory (agent)

MemoryAgentBench

MemoryArena
A 2026 benchmark of interdependent multi-session tasks in web navigation, planning, search and formal reasoning.1617

In Letta, a labeled, size-limited piece of core memory kept in context. The agent edits blocks through tools.010613
