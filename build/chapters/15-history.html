Earlier memory designs, their limits, and where each still fits.

Why look back

These predecessors still fit some small jobs. Avoid rebuilding superseded designs or over-engineering jobs they cover.

Older approaches, one by one

Five groups roughly follow age; retired products follow. Chapter references point to current approaches.

Research roots

1Memory Networks, Neural Turing Machines, kNN-LM, RETRO

Design
Memory Networks added readable/writable long-term storage.1 Neural Turing Machines (NTMs)2 and the Differentiable Neural Computer3 learned task-time working-memory reads/writes. kNN-LM blends frozen-model predictions with distance-weighted following tokens from similar stored contexts.4 New entries need no retraining. RETRO retrieves chunks from a 2-trillion-token database during training and generation.6
Limits
(Reasoning.) Memory Networks, NTMs and RETRO require model-specific training; kNN-LM needs internal vectors unavailable through text-only APIs; prompt-time retrieval uses plain text.
Current fit
Prompt-time retrieval (Chapter 05); Part D stores (Chapters 08 to 12). Still fine for learned-memory research (Chapter 16): kNN-LM adds retrieval after training; RETRO trains with it.

2The 2020 RAG recipe as a finished system

Design
The 2020 RAG model paired a text generator with a dense retriever over Wikipedia passages.5 It combined per-passage predictions weighted by retriever scores and became the outside-knowledge template.
Limits
Its 2020 recipe used one dense retriever.5 See card 5 for retrieval limits.
Current fit
Chapter 05's pipeline over a Part D store. Still fine as a mental model.

Chat history

3Full conversation buffer and sliding window

Design
ConversationBufferMemory kept all messages; ConversationBufferWindowMemory exposed 2k messages (k exchanges); ConversationTokenBufferMemory pruned whole oldest messages to a token budget.161718
Limits
(Reasoning.) Full buffers grow unbounded; windows silently drop old turns. Deprecated for create_agent with checkpoints or Store API. In langchain-classic (legacy classes after v1), ConversationBufferMemory declares since="0.3.1" and removal="2.0.0".19 Its reference says "Since v1.5"; trust your installed warning when these disagree.20
Current fit
A thread_id-keyed checkpointer; middleware drops older messages before calls (Chapter 13).16 Still fine for short single-session chat.

4LangChain summary, vector and entity memory classes

Design
ConversationSummaryMemory, ConversationSummaryBufferMemory, VectorStoreRetrieverMemory and ConversationEntityMemory.16
Limits
Deprecated like card 3. The guide replaces summaries with checkpointing and SummarizationMiddleware.14 A secondary source maps vector and entity memory to Store API on create_agent or an outside service,16 but you must implement extraction and retrieval.
Current fit
Explicit agent state and stores (Chapter 13). Still fine for existing chains with fixed package versions; check each class's support before upgrading.

Retrieval recipes

5Fixed-size chunks with one top-k cosine search

Design
Split documents into chunks, embed them and put the top-k nearest in the prompt without reranking, for a frozen, off-the-shelf generator.
Limits
The retrieval plugin README warns embeddings "may not always be effective at capturing exact keyword matches" and recommends hybrid search.7 (Reasoning.) Fixed cuts can split a fact across chunks.
Current fit
Hybrid search, structure-aware chunks and a reranker (Chapter 05). Still fine for prototypes passing handwritten queries across real question types: required evidence must reach top-k. Cover exact names, ids or codes as well as paraphrases; a relevant-looking chunk without the required fact fails.

6Append-only message embeddings with ada-002

Design
Embed raw messages using text-embedding-ada-002; append and retrieve by similarity without updates or deletion.
Limits
(Reasoning.) Similarity cannot decide what to keep, update or forget. Mem0's paper argues for extracting and consolidating facts, not raw messages.12 OpenAI announced text-embedding-ada-002 on 15 December 2022,21 then text-embedding-3-small and -large on 25 January 2024 as successors.11
Current fit
Current embeddings (Chapter 03) with extraction and updates (Chapter 13). Still fine for immutable-message search with current embeddings. An incompatible model switch requires re-embedding corpus and queries with that model.

Agent loops and memory designs

7AutoGPT and BabyAGI memory (2023)

Design
Early, widely shared demos queried a vector store each cycle. AutoGPT22 executed goals autonomously; BabyAGI created and prioritized tasks. Both appeared in spring 2023; BabyAGI's README marks its original March 2023 version archived.23
Limits
Adoption decline is unmeasured here. (Reasoning.) Unconsolidated steps can crowd retrieval (card 6); missing task state can cause repeated work (cards 3 and 4). AutoGPT continues as a platform project.
Current fit
Checkpointed agent state and curated memory (Chapters 00 and 13). Still fine as a toy for studying how agent loops fail.

8Generative Agents memory stream with reflection

Design
Observations enter a natural-language stream. Retrieval scores recency, importance and relevance; periodic reflections add higher-level memories. The paper tested it with 25 agents in a sandbox.8
Limits
Importance scoring uses one model call per observation.8 (Reasoning.) Calls scale with observations per agent × agents; repeated reflections can compound errors, and contradictions remain active. Mem0 also calls models at write time, extracting facts and updating or deleting conflicts.12 No cited same-workload comparison exists; reflection research continues (Chapter 16).
Current fit
Fact extraction and updates (Chapter 13); consolidation (Chapter 16). Still fine for simulated characters and design research.

9MemGPT, which became Letta

Design
Context serves as RAM; outside storage as disk. Function calls page data between tiers; interrupts, including user messages, manage agent/user control flow.10 It targeted small context windows.
Limits
Only the earlier API is labelled "V1 SDK (legacy)".15
Current fit
Use the current Letta SDK or Letta Code (Chapter 13). Still fine for agent-managed memory with visible tool calls. File-based memory (Chapter 01) is simpler.

Weights, windows and compression

10Fine-tuning on user data as memory

Design
Train on user history to store knowledge in weights (parametric memory).
Limits
RAG lists knowledge updates and provenance as open problems for parametric memory.5 (Reasoning.) Shared-model weights lack per-user records for reliable fact deletion or provenance; facts go stale.
Current fit
Explicit storage (Part D) and retrieval (Chapter 05). Still fine for style, behavior or a domain skill.

11The whole history in a huge context window

Design
Put the whole history or corpus into every prompt.
Limits
(Reasoning.) Prefix caching cuts resending cost and latency; history still grows toward the window limit and competes with the question for attention. In 2023 tests, accuracy dropped for mid-context passages (Chapter 00).9 Anthropic frames the job as the smallest set of high-signal tokens.13
Current fit
Selecting what enters the prompt (Chapters 01, 02 and 05). Still fine when one document fits and is read once, after testing position sensitivity.

12Summary of summaries

Design
Hierarchical roll-ups summarize batches, then those summaries. LangChain rolled new messages into its previous summary.16 Capping the final summary bounds prompt size, not source or intermediate-summary storage; reading it needs no index.
Limits
(Reasoning.) Both can lose detail irrecoverable from their summaries alone. Plant a unique day 2 order number; require its exact recovery from both the first batch summary and final roll-up.
Current fit
Retain originals within policy and regenerate summaries (Chapters 01 and 02). Erasure: delete originals; rebuild or discard their summaries (Chapter 17). Still fine for session orientation under that policy.

Retired hosted and open-source products

OpenAI's Assistants API (threads and file search as memory) shut down on 26 August 2026. The guide maps threads to Responses API Conversations without naming a file-search replacement.24 Inventory threads and file search; test Responses' hosted file_search over your vector store on existing queries before cutover.25 For self-operated retrieval, use Chapter 05 over Part D. Zep ended self-hosted Community Edition maintenance in April 2025, directing users to Graphiti (Chapter 14) or its commercial service.26 Chapter 14 covers setup. Neither migration ran here.

Still fine today, and when to move on

Age alone does not disqualify a design.

Still fine today

  • Short single-session chat: a plain message list.
  • Small-corpus prototype, paraphrased queries: fixed chunks, top-k cosine search. Split evidence: rechunk. Inspect extra candidates: evidence below prompt cutoff means test reranking; absent evidence means change retrieval (Chapter 05).
  • Single document, one read: context window; test key passages at start, middle and end.
  • A style or a skill: fine-tuning.

Time to move on

  • Old facts exceed the prompt-token budget: store and extract (Chapter 13).
  • Missed names, ids or codes: add hybrid search (Chapter 05).
  • Position-dependent answers: select prompt content (Chapter 05).
  • Per-user updates or deletion: use a mutable store (Part D).
  • Summary detail lost: consult originals retained under policy (Chapters 01 and 02).
  • Restart recovery: checkpoints. Cross-thread facts: store. Both needs: combine (Chapter 13).

Verdict: build the smallest thing that holds

Do not start new work on deprecated classes or retired products. LangChain deprecated its memory classes, and newer OpenAI embedding models succeed ada-002. Learned memory (card 1) and reflection streams (card 8) remain research baselines. Do keep the simple answers for small jobs; follow "Time to move on" chapter pointers.
