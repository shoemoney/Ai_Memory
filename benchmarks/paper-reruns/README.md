# Published-paper reruns

Two source-checked evaluations for this book: G46 (HippoRAG 2) first, then G16 (Spiral of Silence). Results and editorial replacement text are in REPORT.md. Datasets, weights, environments, extracted graphs, and caches are temporary and are not distributed here.

## Run

The evaluator runs on a 32-thread x86 CPU, with at most eight embedding threads and no evaluator GPU. Generation runs on an Apple M3 Ultra, 96 GB, through a tunnel to a loopback-only server. Set up that server using `serve.sh` in a dedicated model scratch directory after downloading the Q4_K_M file from `Qwen/Qwen2.5-3B-Instruct-GGUF` at revision `7dabda4d13d513e3e842b20f0d435c732f172cbe`. Name it `model3.gguf`. The server alias is `local-qwen2.5-3b-q4`, port 39950. The server checks memory before loading and stops its own process on elevated kernel pressure. On pressure, wait for recovery, restart the server, then resume the evaluator. Do not alter other servers.

From this directory, with `uv` available and the model endpoint forwarded to localhost:

```sh
bash prepare.sh && bash run.sh
```

`BENCH_SCRATCH` changes the scratch root; `BENCH_ENDPOINT` changes the endpoint (default `http://localhost:39950/v1`). Dependencies are frozen in `requirements.lock`; preparation pins author code and embedding weights. Re-running resumes question outputs and the author's persistent LLM cache. The explicit `force_index_from_scratch=True` option rebuilds graph state from compatible stored embeddings and extraction results, allowing recovery from an interruption before the graph was first saved. Move existing `results/*.jsonl` aside to request new inference rather than reuse checkpoints. Code, corpus construction, source revisions, and scoring are described below.

## G46: HippoRAG 2

Author code: https://github.com/OSU-NLP-Group/HippoRAG, commit `d5c8329422e0a0b834a15874545cb6a74b4f9b26` (MIT). Paper: https://arxiv.org/html/2502.14802v1. Data card: https://huggingface.co/datasets/osunlp/HippoRAG_2, revision `5ec05b38deecc3318bb432c69865959c56058990`. This is a pinned maintained-code revision, not a claim to have recovered the exact original paper-release environment. The experiment fetches the author's Git copy of `2wikimultihopqa.json`; its exact hash is retained in `hipporag2/results/provenance.json`. The checked data card declares no dataset license. No dataset passages or questions are copied into this repository.

Sample 150 of the author's 1,000 2Wiki questions without replacement, using Python's `random.Random(20261122)`, then restore source order. Use the union of **all** supplied contexts for these questions, including distractors, deduplicated by exact passage text. Both systems receive the same 1,117 passages. Corpus selection uses neither the answer nor the support labels. This is a reduced-corpus experiment, not the paper's 6,119-passage full evaluation.

`hipporag2/run.py` invokes the author's `HippoRAG` and `StandardRAG`, including their indexing, graph construction, fact filter, retrieval, and QA prompts. Both use the same local Qwen2.5-3B-Instruct Q4_K_M for generation and `sentence-transformers/all-mpnet-base-v2` on CPU for embeddings, using its 384-token maximum sequence length and pinned to `e8c3b32edf5434bc2275fc9bab85f82640a19130` (Apache-2.0). Qwen 3B weights use the Qwen Research license; see the model card. Temperature is zero; seed is 20261122; QA reads five passages; retrieval retains 20. OpenIE has two workers, 1,024 NER output tokens and 2,048 triple output tokens. QA has 1,024 output tokens. OpenIE uses the author-supported JSON-object response format to prevent malformed JSON from the small local model. It applies to indexing extraction, not QA. A bounded format adapter preserves responses accepted by the native parser and type checks, retrying rejected responses with a typed JSON schema (seeds base+0, base+1, ...; three attempts at first, extended to ten after two chunks exhausted three; finished chunks were unaffected. Two passages, both runaway-repetition loops cut at the token limit on every attempt, receive zero triples and stay in the index as passages; the audit file marks them exhausted-empty). The adapter neither judges nor corrects facts; its rejected and accepted responses are audited. `BENCH_EXTRACTION_CACHE` optionally points to a compatible native LLM cache for resuming prior attempts. Default graph parameters are otherwise retained. These models replace the paper's Llama-3.3-70B-Instruct extractor/filter/reader and NV-Embed-v2 retriever.

Use the author's exact passage recall at 1/5/10/20, normalized QA exact match, and token-overlap F1. No LLM judge is used. Raw per-question answers, scores, retrieved passage hashes, gold passage hashes, and times are checkpointed after each item. `hipporag2/analyze.py` requires all 150 paired IDs and reports 95% percentile intervals from 10,000 seeded paired-question bootstrap samples, including the within-question difference. Those intervals measure question sampling uncertainty conditional on one corpus and model realization, not model-training or corpus uncertainty.

The paper's abstract claims a 7% associative-memory improvement. Its 2Wiki tables give QA F1 71.0 versus 61.5 and recall@5 90.4 versus 76.5 (HippoRAG 2 versus NV-Embed-v2). The abstract's aggregate improvement is not an interchangeable single-dataset recall score. Local scores belong next to these dataset-specific values, with the setup differences retained.

## G16: Spiral of Silence

Author code: https://github.com/VerdureChen/SOS-Retrieval-Loop, commit `56a19847edfc30d1e6e59894d348e1c17ae15114`. No LICENSE file is present at the checked revision, so the harness fetches the source rather than redistributing it. Paper: https://arxiv.org/html/2404.10496v2, particularly Section 3.2, Figure 4, and Appendix A.4. The public author repository contains the sampled NQ questions. Human passages come from the official DPR artifact at https://dl.fbaipublicfiles.com/dpr/data/retriever_results/single/nq-test.json.gz (last modified April 10, 2020). No artifact-specific redistribution license was verified; neither questions nor human passages are stored here. Both inputs are pinned by hash in `spiral-of-silence/results/cohort.json`.

Match the author's 200 NQ questions against that DPR release using lowercase question text with outer whitespace and terminal question marks removed. All 183 matches enter the experiment; the 17 unmatched IDs are recorded. Use the union of each matched question's first 20 DPR contexts, retaining every such context without answer-based filtering. Deduplicate by numeric source document ID, producing 3,632 human documents. This deliberately reduces the original 21-million-passage Wikipedia index and conditions the corpus on a prior DPR ranking.

The harness loads the author's prompt literals and pure `filter_response` function directly from the pinned source through Python AST, and imports the author's `calculate_llm_human_proportion` source-share scorer. It uses the public `facebook/contriever-msmarco` checkpoint at revision `abe8c1493371369031bcb1e02acb754cf4e162fa`, with the same attention-mask mean pooling supplied by the author's SentenceTransformer-based wrapper. The author's Contriever configuration disables normalization and uses maximum inner product; the harness follows that configuration with exact NumPy inner-product ranking and stable document-order tie handling. This replaces the Elasticsearch/LangChain/Faiss orchestration; no reranker is used. The exact bytes of the authors' historical local `contriever-base-msmarco` folder are not published, so the public official checkpoint is a declared substitution. The associated official Contriever repository uses CC-BY-NC-4.0; its model card does not state a separate weight license. Model weights are fetched, not redistributed. Query and document encoding stay on CPU with at most eight threads, with batch size 32 instead of the author's 512. Vector caches are bound to embedding weights, text, normalization, sequence length, and file hashes.

Round zero retrieves from human text only. Round one introduces one zero-shot local response for each of the 183 questions. Rounds two through ten each generate one response per question from the previous round's top five passages, then append all responses to the corpus before retrieval. The local Qwen2.5-3B-Instruct Q4_K_M replaces the paper's diverse generators, and only NQ contributes new text. Temperature 0.7, top-p 1, presence penalty 0.6, 128 output tokens, 100-word truncation, stop strings, and author text cleanup follow the source implementation. Each request has a fixed seed derived from its round and source-order index. Up to three attempts are allowed for responses shorter than five words; all returned attempts are retained. Two concurrent requests share the same round snapshot. The author's ambiguous prompt dispatcher maps both mode labels to zero, so the harness selects the intended literal template explicitly.

Each round retains all 50 retrieved document IDs for every question. Human documents have numeric IDs; generated documents have model-prefixed IDs, as expected by the author's scorer. The unmodified scorer's pooled result must equal the mean of per-question shares. Each mean has a 95% percentile question-bootstrap interval from 10,000 seeded samples. Intervals condition on one shared evolving corpus; questions do not represent independent corpus evolutions. No LLM judge or answer-correctness claim is involved.

The paper adds approximately 4,000 documents per round across multiple generators and datasets. This reduced experiment adds 183 from one local model. Even a ten-round outcome therefore tests the direction of the feedback effect under reduced write volume, not the paper's numerical threshold or an intrinsic preference for generated over human writing. The corpus reduction, generator replacement, and write-volume difference must accompany local numbers.

## Results

Both items ran to completion; see REPORT.md for the full tables with intervals. Headline: HippoRAG 2 beat the dense baseline by 13.8 QA F1 points (95% interval 6.6 to 21.2; published 71.0 versus 61.5) and by 24.7 recall@5 points on 150 questions with a 3B local model. In the reduced Spiral of Silence run the human-written share of the top 50 fell from 100% to 62.9% (interval 61.4 to 64.5) over ten rounds with 183 generated documents added per round; the paper reports under 10% at far higher write volume.
