# Deep Memory Retrieval protocol

Source data: https://huggingface.co/datasets/MemGPT/MSC-Self-Instruct, revision 5138f416f8fa76b75b2e080da87e8a8e346e1500. Dataset card declares Apache-2.0. SHA-256 of msc_self_instruct.jsonl: d3dbea36848b41dc46c0f1548d0ebf74eeaf6390d6f3fe9318e8480dc984495e. Download at runtime; no dataset copy is stored here.

Primary protocols: MemGPT, https://arxiv.org/abs/2310.08560; Zep, https://arxiv.org/html/2501.13956v1; released Zep notebook at https://github.com/getzep/zep-papers/blob/4b7f26cc76cca20743314ba9acb8c2cb6adc42f6/kg_architecture_agent_memory/zep_memgpt_eval.ipynb. Zep's released notebook links the same dataset and alternates A/B speakers within every session. The notebook repository is CC-BY-NC-SA-4.0; LICENSE.prompt-source preserves that license. Local prompt wording is adapted, preserving its perspective, answer/evidence format and permissive grader criteria. Attribution: Zep paper authors and getzep/zep-papers contributors. Changes: local model, shortened prompts, plain JSON Boolean rather than OpenAI structured parsing (a literal Boolean or an object containing is_correct is accepted; surrounding JSON fences are removed), and dense retrieval arm.

Published anchors on 500 conversations: MemGPT 93.4%; Zep 94.8%; full-conversation baseline 94.4%, all with GPT-4-turbo. Zep additionally reports full context 98.0% and Zep 98.2% with GPT-4o-mini. These are not targets to tune toward.

MemGPT also reports ROUGE-L recall and uses a generous topic-matching LLM rubric in Appendix 6.1.2. Its 93.4% accuracy is a judged score, not exact string match. This run follows the released Zep accuracy protocol and does not add ROUGE as another headline.

Selection: Python random.Random(42).sample(range(500), 150), in sampled order. The same 150 items go to both arms. The cohort manifest records every source row index. All previous sessions followed by the current session are included. Roles alternate A/B independently in each session, following the notebook. Persona lists, prewritten summaries, question and gold answer are excluded from context and indexing. The reader always answers as A. All code and data operations run on the x86 CPU host.

Arms:

- Full context: all conversation turns in chronological order, with no input truncation.
- Dense retrieval: adjacent A/B turn pairs are chunks, embedded independently per conversation. CPU sentence-transformers/all-MiniLM-L6-v2, revision 1110a243fdf4706b3f48f1d95db1a4f5529b4d41, Apache-2.0, normalized embeddings, cosine dot product, stable descending rank, top five chunks, then chronological presentation. No reranker or answer-aware index. Embedding-tokenizer truncation counts are retained. CPU thread limits: eight.

Reader: Qwen2.5-3B-Instruct Q4_K_M, exact weights and runtime as Game of 24. Final judge: Qwen2.5-7B-Instruct Q4_K_M. The initial 3B judge labels are preserved in judge-3b-pilot.jsonl and excluded from headline results after direct inspection found obvious misclassifications. Reader generation finishes before the server switches to 7B; only one task model is loaded at once. Temperature 0, seed 42. Reader output cap 384 tokens, judge cap 128 tokens, native 32768-token window. The judge sees the question, supplied gold and full reader response, including its evidence. As in the released Zep grader, topic overlap and equivalent answers are accepted, but incomplete required content is rejected. This permissive rubric can accept an otherwise imperfect answer. No hosted judge or independent human is involved. The first 7B request received HTTP 503 during model warm-up and was retried after health became ready. A literal Boolean response initially stopped the object-only parser; the parser was then broadened to accept that unambiguous Boolean without changing its meaning, and the incomplete cell was retried. No completed label was discarded. Forty answer labels (the first 20 sampled source items, both arms) were written manually by the tester before the 7B judge ran. Forty judgments are checked against those labels by the tester, with agreement and exceptions reported separately. Headline results retain the local judge's labels, not silently replaced audit labels.

Checkpointing: save each reader answer before grading and each completed judgment immediately. On restart the saved answer is reused. JSON/schema failure stops the run rather than fabricating a score. Intervals and paired tests use the same exact methods as Game of 24.

Framework reuse was not run. The inspected longmemeval-frameworks/run.py binds output to its own ROOT/results and initializes shared framework/cache paths, and the LoCoMo adapters coordinate existing model slots and live stores. Safely invoking those shipped adapters unchanged is not possible under the requirement to leave their running jobs and folders untouched. This run provides full-context and dense baselines only, not a Zep or MemGPT implementation.

Final judge weights: https://huggingface.co/Qwen/Qwen2.5-7B-Instruct-GGUF, revision bb5d59e06d9551d752d08b292a50eb208b07ab1f, qwen2.5-7b-instruct-q4_k_m-00001-of-00002.gguf SHA-256 dfce12e3862a5283ccfb88221b48480e58745165de856439950d0f22590580db, and shard 00002 SHA-256 539cf93f78e887edea1c04e2d7d8cdaca9d01dae9c9025bcb8accbe29df3d72a. Qwen2.5 7B is Apache-2.0. Same llama.cpp build and hardware class as the reader.

The reader was restarted after the initial items to explicitly disable parallel tokenizer workers, retaining every completed answer and judgment. Torch, BLAS and Rayon caps are eight and tokenizer parallelism is disabled. Early CPU embedding used eight Torch/BLAS threads with the tokenizer default; exact total tokenizer worker count in that short phase was not captured. No data, prompt, model or scoring threshold was changed based on headline accuracy.

Judge quality control: the retained 3B pilot contains 21 judgments and agrees with the tester on 13/21 overlapping audit cells. Those judgments are excluded from the final score. The final audit has 40 unique cells covering the first 20 sampled histories, both arms, and is recorded in manual-audit.jsonl; reasons explicitly identify topic-only acceptance, missing reference information and contradictions. These are tester judgments, not independent human annotations.
