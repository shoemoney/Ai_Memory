# Game of 24 protocol

Sources checked 2026-11-22:

- Paper: https://arxiv.org/html/2504.07952v1, especially Sections 2 and 3 and Appendix B. GPT-4o direct 10%, DC-RS 99%. The 99% result includes model-generated Python execution and reusable solver code. It is not an isolated measurement of textual memory.
- Official code: https://github.com/suzgunmirac/dynamic-cheatsheet at 5cfe3c37e8e52b1d858d0f3df46e7f17c50991b9. MIT. Generator and cumulative curator templates are included with upstream attribution in LICENSE.upstream.
- Standard public puzzle split loaded by upstream run_benchmark.py: https://huggingface.co/datasets/turingmachine/meta-prompting, revision dfc146f81138b9bcd70069196545015e40be122b, GameOf24 (100 examples). Dataset card does not declare a license. Data is fetched at runtime, not redistributed. Parquet SHA-256: 047e74473a0a9b316072fe85bb837de6e5d8139e0178e9742a291d6a81d5de6b.

All 100 puzzles in published dataset order, paired. No sampling or tuning based on correctness. Temperature 0, seed 42, generation cap 768 tokens, curation cap 512 tokens with a request to keep memory under 200 words. Same local model for generation and curation. The curator sees the prior memory, input and generated response but never the gold answer or deterministic correctness label. Empty initial memory. Completed items checkpoint independently; incomplete calls are rerun after interruption. A restart replays stored memory states.

Local arm is a minimal DC-Cumulative implementation, not the headline DC-RS configuration. It uses upstream prompts and one optional Python execution followed by one answer call per puzzle. Python code allows only standard arithmetic/combinatorics libraries, blocks private attributes and dangerous builtins, and has time and resource limits. No correct solver is provided by the tester. The direct arm asks for only an expression without tools. Thus instruction style, curation calls and tools differ as well as memory. This comparison does not isolate memory's causal contribution.

Scoring uses a restricted arithmetic AST and exact rational arithmetic: the expression must use precisely the multiset of four provided integers, only + - * / and parentheses, and evaluate to 24. This replaces upstream unrestricted eval and its 0.001 tolerance. Answer tags are extracted if available, otherwise the entire response is scored; prose is not heuristically mined for a correct expression. No judge. Per-item traces, execution outputs, memory state, stop reason and timing are retained.

Intervals are two-sided 95% Clopper-Pearson binomial intervals. Paired difference interval is conservative exact coverage: difference of two discordance-probability intervals, each at 97.5%, with Bonferroni coverage at least 95%. Also report exact McNemar p. The puzzle set is fixed, so intervals describe repeated-population uncertainty under an exchangeability assumption, not uncertainty about the fully enumerated 100-puzzle score.

Model: Qwen2.5-3B-Instruct Q4_K_M, GGUF SHA-256 626b4a6678b86442240e33df819e00132d3ba7dddfe1cdc4fbb18e0a9615c62d. Primary weight source: https://huggingface.co/Qwen/Qwen2.5-3B-Instruct-GGUF/resolve/7dabda4d13d513e3e842b20f0d435c732f172cbe/qwen2.5-3b-instruct-q4_k_m.gguf (API digest matched). The starting weight file was copied from an existing benchmark cache without modifying that cache. Model family license is Qwen Research, not Apache-2.0. Server llama.cpp build 12359, commit b1b770d90, AppleClang 21.0.0. Apple M3 Ultra, 96 GB unified memory; shared with other running jobs. Generation only on the Mac, all code and scoring on a 32-thread x86 CPU host. Context 32768, one slot, default KV precision. No host GPU used for computation.

An initial generation-cap trial of 2048 was interrupted before its DC item completed because measured shared-host throughput was about 12 tokens/s. No completed DC outputs were discarded and no score-guided cap choice was made. The first direct answer was already complete in 15 tokens and is retained. Two incomplete first-item DC calls were interrupted during harness setup. These discarded calls cannot contribute to memory or scores.
