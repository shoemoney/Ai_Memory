# Flip probes on the varloop model, amended run (2026-11-25)

Read `AMENDMENT-1.md` first: the registered settings gave no final answers (pilot 1, 0 of 8 eligible), so this run measures **the model's direct answer without visible reasoning** (turn prefilled with a text message), on **160 of the 400 registered items** (40 per stratum, seed 1701), 32 new tokens, TML-d24-varloop-research, greedy, 1 pass vs 3 passes, layers 6/11/17.
Run: the Mac Studio, 142 min, 20 GB RSS (91 GB peak footprint), judges stopped for the duration and restarted afterwards. Analysis on the workstation: `probes.py` (fixed C=1, 256-dim signed-hash sketch, 5-fold family-grouped CV, leave-one-stratum-out, 1,000 family-cluster bootstrap), `controller.py`. Files: `amended/`.

## Conclusions
1. **A probe on the 1-pass state beats entropy and margin at predicting token-level 1-vs-3-pass flips inside a stratum for code and recall, and fails everywhere else.** Token-level flips: 386 of 3,143 generated positions (12.3%). Grouped-CV AUC (pre-registered rule: 95% bootstrap interval of the gain over entropy must exclude 0, and also beat margin):
   - code (1,259 tokens, 197 flips): residual AUC 0.927 vs entropy 0.863, margin 0.886; gain over entropy +0.064 [+0.022, +0.102], over margin +0.041 [+0.004, +0.075]. Beats both. The message feature is similar (0.932, +0.069 [+0.020, +0.108] over entropy, +0.046 [+0.006, +0.079] over margin).
   - recall (493 tokens, 31 flips): residual 0.881 vs entropy 0.724, margin 0.750; +0.156 [+0.027, +0.237] and +0.131 [+0.001, +0.211]. Beats both (the interval over margin only just excludes 0); message does not (+0.126 [-0.027, +0.224]).
   - memory (1,231 tokens, 144 flips): probes are **worse** than entropy (residual -0.115 [-0.151, -0.079]); two_hop (160 tokens, 14 flips): no gain (residual -0.027 [-0.075, +0.019]).
2. **The probes do not transfer across strata.** Leave-one-stratum-out, no probe beats entropy in any stratum (gain over entropy from -0.06 to -0.41; gate-norm is closest at -0.01 to -0.16). So the signal found in code and recall is stratum-specific, not a general "this token needs more loops" detector.
3. **Answer-level flips: 78 of 160 items were eligible and 28 of those flipped (35.9%, Wilson 95% [26.1%, 47.0%]).** Eligibility by stratum (final answer in 32 tokens at both depths): recall 35/40, two_hop 40/40, memory 3/40, code 0/40. Memory and code answers mostly kept reasoning in plain text and were cut off, so they are censored, not "no flip"; the answer-level result is a recall and two_hop result only.
   Flip counts: recall 11/35 (31%), two_hop 14/40 (35%), memory 3/3. In the 8-item pilot 0 of 4 eligible items flipped (rate 0%, Wilson [0, 49%]), below the 10% flag, and the 160 was run anyway as instructed; the full-run rate is far higher, so the pilot rate was a small-sample artefact.
   Answer-level probe results are not reliable: two_hop residual AUC 0.89 vs entropy 0.64, margin 0.54, gain over entropy +0.25 [+0.05, +0.46] and over margin +0.35 [+0.15, +0.55] (n = 40, 14 positives, beats both) but the leave-one-stratum-out version is +0.06 [-0.23, +0.35]; recall shows no gain (+0.07 [-0.23, +0.40]). One of two tests passing at n = 40 with unadjusted intervals is weak evidence.
4. **Early-exit policy table (`amended/pareto.md`)**: fixing one pass agrees with 3-pass argmax on 84.4% of code tokens, 93.7% of recall, 91.3% of two_hop; KL-threshold exits reach 100% agreement at about 2.4 to 2.7 mean passes, i.e. they save at most about 10 to 20% of passes at zero loss on this data; probe-gated policies trade agreement for passes (for example code 2.0 passes at 97.9%). These agreement numbers are teacher-forced token agreement, not task accuracy.

## Limits
Reduced n (160 of 400 registered), the measured quantity changed to no-reasoning direct answers, one model, 32 tokens, greedy, one run. Recall and two_hop have only 31 and 14 flipped tokens, so their intervals are wide, and all intervals are unadjusted for the many feature x stratum x task comparisons; the code result is large and consistent across two features, the others are weaker.
Sketching to 256 dimensions may under-use the residual. Gate-norm is retrospective (measured during pass 2). "Does not beat entropy" outside code and recall is the result and no feature search was done after seeing labels.
