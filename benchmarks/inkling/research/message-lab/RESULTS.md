# Inter-pass message lab: results on the varloop model (2026-11-25)

Model: TML-d24-varloop-research (packed native weights, mlx-lm PR #2086), macstudio. Registered design: README.md. 200 discovery pairs and 100 held-out pairs (held-out = template 2), 18,000 JSON records, 22,800 hooked forwards, cache-free prefills, no sampling.
Pairs are the unit of analysis (both swap directions kept together); intervals are 95% percentile bootstrap over pairs (4,000 replicates, seed 16). Margin = answer-token logit margin. Raw: `runs/varloop-{discovery,heldout}/results.jsonl`, report `runs/varloop-report/` (analysis.json, controls.md, swap/zero/injection SVGs).
Run time: discovery 1 h 40 min, held-out 33 min (about 0.3 s per forward). The Mini replication (README) was not run.

## Conclusions
1. **Swapping the bridge-span message does not move the answer toward the donor.** The registered primary endpoint (held-out, boundary 2 to 3, layers 12-17, swap minus irrelevant-position swap in donor-directed shift) is **-0.003 logits [-0.015, +0.010]**, entirely inside the pre-registered +/-0.1 null band: no material bridge-specific effect at that site. Same for all other swap cells: donor shift between -0.06 and +0.04 logits, argmax-to-donor rate 0 to 5% (the random-message control spans the same 0 to 5%), flip rate 0 to 3%. Discovery agrees (primary cell swap minus irrelevant +0.002 [-0.013, +0.015]).
   Reading: at these sites the identity of the bridge entity is not carried in a form that a transplanted message can redirect, or the answer is also recoverable from the residual stream and attention, so a message swap is overridden.
2. **The messages as a whole matter, and matter more for two-hop than single-hop on discovery.** Zeroing all messages at all positions and boundaries (discovery) lowers the two-hop margin by 2.54 logits vs intact 3-pass [-2.75, -2.33] (4.61 to 2.07) and single-hop by 1.76 [-2.15, -1.35]; the paired two-hop minus single-hop damage is **0.78 logits [0.35, 1.20]**. On the held-out template the same contrast is **0.27 [-0.19, 0.72]**, i.e. not distinguishable from zero, and zeroing hurt little there (two-hop -0.22 [-0.43, -0.00]; single-hop +0.06 [-0.37, +0.48]).
3. **Injecting a 3-pass message into a 1-pass computation recovers part of the 1-to-3-pass gain only in the early block, and only in discovery.** Layers 6-11 at the 2 to 3 boundary: 45% of the gap recovered [26%, 83%]; at 1 to 2, 26% [9%, 53%]; layers 12-17: about 0 to 1% (all intervals contain 0). On the held-out template the 3-pass model is *worse* than the 1-pass model (margin 1.30 vs 1.98, gap -0.68 [-0.83, -0.54]) so "recovery" is ill-defined; the injection cells there are near 0 (the one interval excluding zero, layers 6-11 boundary 2, has the wrong sign: -15% [-30%, -1%]).
4. **Template dependence is large and unexplained.** On discovery pairs 3 passes beat 1 pass on two-hop (+0.42 logits [0.23, 0.61]); on the held-out template they lose by 0.68. Conclusions 2 and 3 therefore do not replicate across templates and should be read as discovery-only observations.

## Limits
Two templates only; margins on a synthetic bridge task, not LongMemEval. Swap tests one 2 to 3 token span per pair, in six layers at a time; a null there does not rule out a distributed message. Sufficiency (injection) adds a gate path absent in native one-pass execution.
Many cells were examined; apart from the registered primary endpoint, intervals are unadjusted and exploratory. Pairs within a template share structure, so 300 pairs are not 300 independent facts. Single model checkpoint; native NVFP4/MXFP8 weights; the model was run at 3 passes (intact) and 1 pass (comparison); 2 and 5 passes were not used.
