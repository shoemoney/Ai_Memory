# Optional real backends

The registered comparison uses only the fake backend in the recipe's `tools.sh`; no real backend was run for this study. The earlier recipe revision (`recipe-trained-tools`, commit `08876d4`) also offered `TOOLS_BACKEND=real`, which sends search to any SearXNG instance that serves `/search?q=...&format=json` (set `SEARXNG_URL`), reads pages with curl, and forwards image generation and model consultation to user-supplied HTTP form endpoints (`IMAGE_GEN_URL`, `ASK_MODEL_URL`) that accept `prompt` or `question` and return short plain text. Those are adapter contracts, not bundled services. The calculator is a small AST evaluator, and `remember` and `recall` use a caller-owned local file in both modes. Fake image paths and URLs are fixture strings, not media files. Real traces carry separate licensing obligations and do not belong in the fake-backend comparison. The upstream-bound recipe (`recipe-trained-tools-pr`) dropped the real backend.
