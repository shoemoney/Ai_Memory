The preliminary Qwen trial incorrectly retained a Gemma-specific system-message folding adapter. One Mem0 question had been scored before this protocol error was found; its result and the incomplete Graphiti work are preserved under `results/preflight/qwen-folded-system/` and excluded from primary results. The primary protocol restores Qwen's native system/user roles and exact tokenizer budgeting, and reruns both frameworks on the unchanged fixed IDs. The reader, judge, references, and sampling were not changed in response to that preliminary score.

Serving was moved from Apple M1 Ultra, 64 GB, to Apple M3 Ultra, 96 GB, because permanent warning-level pressure and almost-full swap on the first machine prevented safe resumption. The M1 scratch, owned model server, and tunnel were removed, with cleanup proof in `results/hardware-migration/apple-m1-ultra/`. The one completed native-protocol Mem0 M1 row is retained and labeled; incomplete Graphiti work restarts on M3. Model files, settings, question IDs, and scores are unchanged by the hardware move, and timing summaries are separated by hardware class.

A conservative guard initially applied the 40% load threshold to every request, including reuse of already-loaded weights at normal kernel pressure. This was corrected without changing model prompts or generation settings: reuse now requires a verified owned server PID and a valid last-successful-model lease, while every new load still requires 40% free memory and normal pressure. Leases are cleared before switches and invalidated on failures or PID changes; only the owned model server can be released to make room for the next model.

Transport recovery at 11:41 UTC: the 900-second client timeout abandoned still-running generations and queued retries. The owned worker/server were restarted with a 3600-second HTTP timeout under the same absolute deadline; 36 completed Graphiti parts and their graph were preserved, and only four exact unfinished Episodic stubs with no relationships were deleted before retry. Generation settings did not change. An unrelated redundant lease-finalization call after item checkpointing was removed because API calls already finalize their own lease.
